# Spring Tutor Frontend

Frontend for Spring Tutor, an AI-powered Spring Framework and Spring Boot learning assistant.

## Features

- Chat interface similar to ChatGPT
- Streaming responses
- Spring Boot course-based RAG system
- Connected to FastAPI backend
- Responsive UI built with React + TypeScript + Vite

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- FastAPI Backend
- Pinecone Vector Database
- Hugging Face Embeddings
- GPT OSS 120B

## Local Setup

Clone the repository:

```bash
git clone https://github.com/Roushan-cse/spring-tutor-frontend.git
cd spring-tutor-frontend
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build project:

```bash
npm run build
```
